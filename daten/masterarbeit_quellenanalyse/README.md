# Quellen einer Masterarbeit analysieren

**Challenge:** B – Die Quellen einer Masterarbeit analysieren (siehe [`anleitungen/02_challenges.md`](../../anleitungen/02_challenges.md))
**Flow:** `02 Masterarbeit – Quellen analysieren`

## Daten

- [`beispiel_masterarbeit.pdf`](beispiel_masterarbeit.pdf): eine fiktive Masterarbeit mit 17 echten Quellen. Sie ist kein echtes Dokument und wird von [`scripts/beispieldaten_erzeugen.py`](../../scripts/beispieldaten_erzeugen.py) erzeugt.

## So nutzt ihr sie

Im Baustein *Abschlussarbeit (PDF)* des Flows die Datei hochladen und im Playground einen Auftrag geben, z. B. *Analysiere die Quellen dieser Arbeit.* Flow 02 findet 17 von 17 Quellen.
