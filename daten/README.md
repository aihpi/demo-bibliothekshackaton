# Daten

Ein Ordner pro Use Case, jeweils mit einer Beschreibung (`README.md`) und den Daten, die dazugehören.

| Ordner | Use Case | Flow | Daten |
| --- | --- | --- | --- |
| [`referenz_checker/`](referenz_checker/) | Challenge A: Der Referenz-Checker | `01 Referenz-Checker` | Literaturliste mit eingebauten Fehlern |
| [`masterarbeit_quellenanalyse/`](masterarbeit_quellenanalyse/) | Challenge B: Die Quellen einer Masterarbeit analysieren | `02 Masterarbeit – Quellen analysieren` | Fiktive Masterarbeit als PDF |
| [`schulungsplanung/`](schulungsplanung/) | Schulungsplanung einer Hochschulbibliothek | `05 Schulungsplanung` | Beschreibung des Use Case, Vorlage der HTML-Tabelle für die Lernplattform |

Langflow sieht diesen Ordner unter `/app/daten`. Zum Ausprobieren ladet ihr die Dateien im Baustein *Read File* hoch oder kopiert ihren Inhalt in den Playground.
